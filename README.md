# E-Commerce Project (MERN Stack)

A modern e-commerce platform with a voice-enabled search and a sleek React frontend.

## 🚀 Features

- **Voice Search**: Advanced voice-enabled product discovery.
- **Full-Stack Integration**: Robust Node.js/Express backend with MongoDB.
- **Modern UI**: Responsive and premium React frontend.
- **Authentication**: Secure user login and registration (JWT).
- **Admin Dashboard**: Comprehensive management of products and users.

## 📁 Project Structure

E-Commerce/
├── Backend/          # Node.js Express server, models, controllers
├── FrontEnd/         # React/Vite application
└── README.md         # Project documentation

## 🛠️ Tech Stack

- **Frontend**: React, Vite, CSS (Vanilla)
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **AI/ML**: Groq API (for voice/text processing)

## 🏁 Getting Started

### Prerequisites

- Node.js (v18+)
- MongoDB (Local or Atlas)

### Installation

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd E-Commerce
   ```

2. **Setup Backend**:
   ```bash
   cd Backend
   npm install
   cp .env.example .env
   # Update .env with your credentials
   npm run dev
   ```

3. **Setup Frontend**:
   ```bash
   cd ../FrontEnd
   npm install
   cp .env.example .env
   # Update .env if necessary
   npm run dev
   ```
### run the project
   backend: npm start
   frontend: npm run dev
